Пользовательское соглашение сервиса «Бот Диспетчер»

Для сайта botdispatcher.ru, личного кабинета и чат-бота MAX

1. Общие положения

Настоящее Пользовательское соглашение регулирует использование сервиса «Бот Диспетчер», сайта botdispatcher.ru, личного кабинета и чат-бота в MAX.

Владельцем и правообладателем сервиса является Общество с ограниченной ответственностью «Городская метрологическая служба», ИНН 1658217847, ОГРН 1191690041465, адрес: 420034, Республика Татарстан, г. Казань, ул. Декабристов, д. 115.

2. Назначение сервиса

«Бот Диспетчер» предназначен для автоматизации взаимодействия управляющих организаций с жителями: выявления обращений, оформления заявок в личном диалоге, маршрутизации заявок, уведомления о статусах, работы сотрудников УК в личном кабинете и интеграции с информационными системами.

3. Использование чат-бота MAX

Пользователь самостоятельно решает, оформлять ли обращение через чат-бот. При переходе к оформлению заявки сервис сообщает, в какую управляющую организацию и по какому дому направляется обращение.

Пользователю рекомендуется не публиковать номер телефона и иные избыточные персональные данные в общем домовом чате. Данные, необходимые для заявки, запрашиваются в личном диалоге с ботом.

4. Права и обязанности пользователя

  • предоставлять достоверные сведения, необходимые для рассмотрения обращения;
  • не использовать сервис для противоправных действий, спама, распространения вредоносных файлов или попыток несанкционированного доступа;
  • не передавать чужие персональные данные без соответствующего основания;
  • соблюдать права других пользователей и требования законодательства.

5. Работа сервиса

Сервис может направлять уведомления о регистрации заявки, необходимости уточнения, изменении статуса и завершении работ. Конкретный порядок рассмотрения обращения и сроки исполнения определяются соответствующей управляющей организацией и применимыми требованиями.

ООО «ГМС» вправе выполнять технические работы, обновлять функционал и временно ограничивать отдельные функции для обеспечения безопасности и стабильности сервиса.

6. Персональные данные

Порядок обработки персональных данных раскрывается в Политике в отношении обработки персональных данных, доступной по ссылке из MAX и на сайте (Политика в отношении обработки персональных данных).

По обращениям жителей в УК оператором персональных данных для цели приема и исполнения обращения является соответствующая управляющая организация, а ООО «ГМС» осуществляет техническую обработку по ее поручению. По собственным целям ООО «ГМС» может выступать самостоятельным оператором.

7. Интеллектуальные права

Исключительные права на программное обеспечение и сервис «Бот Диспетчер» принадлежат ООО «ГМС», если иное прямо не установлено договором. Пользователю предоставляется только право использовать доступный функционал сервиса по назначению.

8. Ограничение ответственности

ООО «ГМС» отвечает за функционирование принадлежащей ему программной части сервиса в пределах законодательства и заключенных договоров. Решения по существу обращения жителя, организация работ по дому и исполнение заявки находятся в зоне ответственности соответствующей управляющей организации.

9. Заключительные положения

Актуальная редакция Соглашения размещается на botdispatcher.ru. Продолжение использования сервиса после публикации новой редакции означает применение актуальных условий к последующему использованию, если законодательство не требует иного способа принятия изменений.
